# Sandbar v0.1.0-beta.1

This beta targets Linux amd64, with native acceptance on Ubuntu 24.04.
Source builds require Go 1.27.2 or later for standard-library security fixes.
`markjeee/sandbar` remains private for release review.
Public download verification remains pending until the repository becomes public.

## Changes

- Manage multiple `.sandbar.localhost` routes with `add`, `add --replace`, `rm`, and `ls`.
- Create an empty configuration with `init`. The original hostname/upstream form remains supported.
- Read version 1 configuration and preserve a backup when route mutation converts it to version 2.
- Apply validated route changes to running Caddy, with a private recovery journal.
- Apply edited source configuration with `reload`.
- Report router state and bounded HTTPS route checks with `status`.
- Install a static executable from a versioned package or build checkout source with Go.
- Distribute Sandbar under the MIT license.

## Installation

The versioned installer needs public access at this URL.
Use it after the repository becomes public:

```sh
curl -fsSL https://github.com/markjeee/sandbar/releases/download/v0.1.0-beta.1/install.sh | sh
```

Add `sh -s -- --bin-dir "$HOME/bin"` in place of `sh` to select another destination.
The default destination is `~/.local/bin`.
Run `sh ./install.sh` inside a checkout to build local source instead.

## Limits

Install Caddy separately. Sandbar remains a CLI and starts no persistent Sandbar process.
HTTP and HTTPS listeners stay on loopback. Default router ports remain 80 and 443.
Upstreams must use loopback IP addresses or `localhost`.
HTTPS upstreams retain certificate verification. Custom upstream trust settings are deferred.
Certificate trust requires explicit `trust` and `untrust` commands.
`status` checks reachability. It does not establish browser trust, system DNS success, OS listeners, or application health.
Foreground debugging remains deferred to Phase 4.

## Release acceptance

Local installer tests use controlled release fixtures.
These tests do not establish public availability.
The release record holds final native, browser, and release asset acceptance.
